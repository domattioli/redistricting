      Why a mesh

      Districting is a cutting problem. Cut a web of neighbourhoods into pieces with equal people, one piece each, and short borders. Ocean modellers solve the same problem when they split a mesh across processors. This tool comes from that work (ADMESH and CHILmesh).

      The Mesh size view paints cell size by population: small in cities, large in empty land. Meshing to this size map did not beat cutting the block groups directly. The solver does not use it.

      Four methods on the same block groups, the same mesh and the same scoring code. “Population gap” is how far the worst district is from an equal share (smaller is better). “Compactness” is the average Polsby-Popper score: 1 means a perfect circle, and values near 0 mean long, stringy shapes (higher is better). “Seconds” is run time. The GerryChain row is the most compact map found in 5,000 random steps.

      Not a new method. It combines published techniques: Hess (1965), Cohen-Addad, Klein and Young (2018), and the METIS border swap. GerryChain ReCom samples many maps, so its population gap says little. Shortest splitline wins on compactness in 2 of 3 states. † In California, shortest splitline split one district into pieces.

      How it works. Block groups form a web of neighbours (a Delaunay triangulation clipped to the state; islands link across water). Districts grow from starting centres with equal population (a balanced power diagram). Stray pieces reattach. Border swaps even out the populations. Inputs are only head counts and locations. Starts are random and weighted by population, so runs differ slightly.

      Data and limits. Population: 2020 Census block groups and 2020 seat counts. Districts are within about 0.2% of equal; courts need near-exact. Votes: presidential results estimated down to block groups, from VEST precinct data spread by the ALARM Project (CC BY 4.0 / CC BY-SA 4.0) and 2024 county totals from Dave’s Redistricting and the Redistricting Data Hub (CC BY-SA 4.0). Seat counts show presidential votes, not House races. No Voting Rights Act analysis. Maps are hypothetical.
