Constraint layers

λstate 0
λgeo 0
λcz 0
Each λ multiplies the length of block-group links that cross the line by 1 + λ. The solver measures distance along links, so a crossing becomes a detour: districts prefer to stop at the line. λ = 0 ignores it. Numbers: your map's districts that cross each line. Applies to the next solver run and to new proposals.
